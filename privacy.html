Privacy Policy

Last updated: 26 November 2026

Overview

WykesWatts is a personal cycling training application built for private use by a single individual. It is not a commercial product and has no registered users other than its owner.

This privacy policy describes how the application handles data, in compliance with the requirements of the Garmin Connect Developer Program and applicable data protection regulations.

Data Controller

This application is operated by James Wykes, Frankfurt am Main, Germany. For any privacy-related enquiries, contact: privacy@wykeswatts.com

Data Collected

WykesWatts may access and process the following categories of data, all belonging to the application owner:

  • Garmin Connect health data — heart rate variability (HRV), resting heart rate, sleep duration and score, body battery, stress score. Retrieved via the Garmin Health API for personal training monitoring.
  • Garmin Connect activity data — completed workout records including power, cadence, heart rate, duration, and distance. Used to track training load and performance.
  • Strava activity data — cycling activities, training stress scores (TSS), and fitness metrics. Retrieved via the Strava API for training load analysis.
  • Live sensor data — real-time power, cadence, and heart rate from connected Bluetooth devices (smart trainer, heart rate strap) during active workout sessions. Processed locally in the browser only.

How Data Is Used

  • To display daily health and readiness metrics on the application dashboard
  • To plan and execute structured cycling workouts via ERG mode control of a smart trainer
  • To upload completed workout files to Garmin Connect and Strava for record-keeping
  • To calculate training load, fitness trends, and readiness scores

Data is never sold, shared with third parties, or used for any commercial purpose.

Data Storage

No personal data is stored on external servers operated by this application. API tokens (Garmin, Strava) are stored in the user's own browser local storage and transmitted only to the respective authorised API endpoints. No database or backend data store is maintained by WykesWatts.

Serverless functions hosted on Netlify act as OAuth relay endpoints only; they do not log or retain any health or activity data.

Third-Party Services

  • Garmin Connect API — governed by Garmin's Privacy Policy
  • Strava API — governed by Strava's Privacy Policy
  • Netlify — hosting and serverless functions, governed by Netlify's Privacy Policy

Your Rights

As this application is used exclusively by its owner, all data accessed belongs to the operator. Rights to access, correction, and deletion are exercised directly through the respective third-party platforms (Garmin Connect, Strava).

Changes to This Policy

This policy may be updated to reflect changes in the application's functionality or applicable regulations. The date at the top of this page indicates when it was last revised.
